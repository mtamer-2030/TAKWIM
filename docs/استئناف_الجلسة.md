## ملفّات الذاكرة الثلاثة (تُقرأ باردةً)
1. **`CLAUDE.md`** — القرارات المعماريّة، الثوابت التي لا تُخالَف، الملفّات المفتاحيّة،
   وملخّصُ «أحدث التطويرات».
2. **`docs/فهرس_المشروع.md`** — خريطةٌ كثيفةٌ للوحدات/الجداول/المسارات (اقتصاد توكنز).
3. **`ROADMAP.md §8`** — سجلُّ كلّ بندٍ أُنجز، الأحدث في الأسفل.

## الحقائق الثابتة
- **الفرع النشط:** `claude/new-session-zcmzcl` (كلّ العمل يُدفَع إليه).
- **التشغيل:** `.\start.bat` (ويندوز، يدير `.venv`).
- **الاختبار قبل كلّ التزام:** `python -m pytest` (يجب أن يبقى **أخضرَ كاملاً**).
- **قاعدة البيانات على حاسوب الأستاذ فقط** (`data/philotech.db`) — لا تُعدَّل من السحابة.

## الثوابت (لا تُخالَف)
- المخطّط **مُجمَّد** (Alembic): تطويرُ الميزات **بلا هجراتِ بيانات**.
- النموذج المحلّي (Ollama) **ممنوعٌ من مسار الاستيراد**.
- الجلسة في القاعة **محلّية بحتة** (LAN)؛ السحابة للتحضير فقط.
- لا تُحذف/تُعطَّل أسئلةٌ لنتيجة، ولا تُصفّر مصادقةٌ بلا نقطة.
- **حذفُ جلسةٍ يحفظ النتائج** (سجلّ الجلسة فقط يُحذف).
- لكلّ ميزةٍ اختبارٌ يمرّ + التزامٌ برسالةٍ عربيّة + تحديثُ `ROADMAP.md §8`.

## دورة العمل لكلّ ميزة
1. افهم الطلب واقرأ الشيفرة المعنيّة (لا تُخمّن).  2. نفّذ التغيير + اختبار.
3. `python -m pytest` (كامل).  4. `git commit` برسالةٍ عربيّة (ما قبل/ما بعد).
5. `git push -u origin claude/new-session-zcmzcl`.  6. حدّث `ROADMAP.md §8`.

## أفكار التطوير القادمة (اختِر منها)
- **بيداغوجيّاً:** تحليل المفردات (صعوبة/تمييز)، مجموعات الدعم التلقائيّة، بنك الأسئلة،
  المراجعة المتباعدة، الحكم المقارن ACJ للمقالات. (تفاصيلها في مرجع البيئات التعليميّة.)
- **كشفٌ تلقائيّ للتلاميذ المكرّرين** (نفس الاسم/القسم) للدمج بنقرة.
- **عرضٌ تراكميّ للقسم كامل** (متوسّط القسم عبر الزمن).
- **التغليف (آخِراً):** ‎.exe للأستاذ (PyInstaller+pywebview) + PWA للتلميذ.
