# مِحَكّ (mihakk) — نظام التقويم الصفّي في الفلسفة

نظام استجابة صفّي **محلّي** لأستاذ فلسفة واحد، عبر ٨ أقسام في ٣ مستويات.
كل ما يجري **داخل القاعة** يُصحَّح بقواعد يقينية لا باحتمال، و**لا نموذج ذكاء
اصطناعي يعمل أثناء أي جلسة** — لا محلّي ولا بعيد. الذكاء الاصطناعي موضعه الوحيد
طاولة الأستاذ في البيت، بعد الجلسة، مقترحاً لا حاكماً.

- لا إنترنت في القاعة، ولا CDN، ولا خطوط من الشبكة — خطوط النظام فقط.
- لا حساب ولا كلمة سرّ للتلميذ؛ الدخول برمز قصير.
- واجهة عربية RTL بالكامل، للهاتف أوّلاً.
- بلا تلعيب: لا لوحة صدارة، لا عدّاد تنازلي، لا ترتيب بالسرعة، لا أصوات.
- **التلميذ لا يرى نقطة أبداً.**

---

## ١. المتطلّبات

- **ويندوز 10** (طُوِّر ليعمل على HP ZBook مع 32GB RAM) — يعمل كذلك على أي
  جهاز Linux/macOS للتجربة.
- **Python 3.11 أو أحدث**. ثبّته من [python.org](https://www.python.org/)
  وفعّل خيار **Add Python to PATH** أثناء التثبيت.
- شبكة محلّية (راوتر Huawei B310s-22 أو أي راوتر)، وكابل إيثرنت.

## ٢. التشغيل السريع

انقر نقراً مزدوجاً على **`start.bat`**. في المرّة الأولى:

1. يُنشئ بيئة افتراضية `\.venv` ويثبّت المكتبات من `requirements.txt`.
2. ينسخ `config.ini.example` إلى `config.ini` (عدّل كلمة السرّ فيه).
3. يشغّل الخادم على `http://0.0.0.0:8000`.

اترك النافذة السوداء مفتوحة طوال الحصّة. للإيقاف: `Ctrl+C`.

- **لوحة الأستاذ:** `http://192.168.1.50:8000/teacher`
- **دخول التلاميذ (QR):** `http://192.168.1.50:8000`

يدوياً بدل `start.bat`:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy config.ini.example config.ini
python run.py
```

## ٣. إعداد الشبكة يوم التشغيل الأوّل (اقرأه — هنا يُعطَّل النظام غالباً)

### أ) ثبّت عنوان IP للحاسوب على `192.168.1.50`

لوحة التحكّم ← الشبكة والإنترنت ← Change adapter options ← اضغط بزرّ الفأرة
الأيمن على اتصال الإيثرنت ← Properties ← Internet Protocol Version 4 (TCP/IPv4)
← Properties ← **Use the following IP address**:

```
IP address:      192.168.1.50
Subnet mask:     255.255.255.0
Default gateway: 192.168.1.1
```

نطاق DHCP للراوتر من `.100` إلى `.200`، فالعنوان `.50` خارجه ولا يتصادم.

### ب) افتح المنفذ 8000 في جدار حماية ويندوز (أكثر سبب يُعطّل اليوم الأوّل)

افتح **PowerShell كمسؤول** ونفّذ:

```powershell
New-NetFirewallRule -DisplayName "mihakk 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
```

بدونها ترى الهواتف «تعذّر الاتصال» رغم أنّ الخادم يعمل.

### ج) اربط الحاسوب بالراوتر بكابل إيثرنت

أثبت من اللاسلكي وقت الذروة. الهواتف تبقى على واي‑فاي الراوتر نفسه.

### د) رمز QR واحد ثابت

من لوحة الأستاذ ← **رمز QR**. اطبعه وعلّقه، أو اعرضه على السبّورة الرقمية.
يشير دائماً إلى `http://192.168.1.50:8000`. إن غيّرت العنوان، عدّل
`public_url` في `config.ini`.

> السعة: يعمل النظام بـ٢٥ اتصالاً متزامناً بلا تدهور؛ الثنائيات هي الوضع
> الافتراضي في التمرينات.

## ٤. الإعداد (`config.ini`)

```ini
[teacher]
password = ضع-كلمة-سرّ-قوية

[server]
port = 8000
public_url = http://192.168.1.50:8000

[evening_ai]
enabled = false        ; المساعدة المسائية وحدها؛ لا تُستدعى داخل أي جلسة
api_key =              ; يبقى هنا فقط، لا في الكود ولا في القاعدة
model = claude-sonnet-4-5
```

`config.ini` **لا يُرفع إلى المستودع** (مُستثنى في `.gitignore`).

## ٥. سير العمل

1. **استيراد اللائحة** (لوحة الأستاذ ← اللوائح): ملفّ CSV بالأعمدة
   `class_label,roster_id,full_name`. الاستيراد **تراكمي**: يُحدَّث الاسم
   للموجود، ويُضاف الجديد، ولا يُحذف أحد. رمز الدخول يُولَّد مرّة واحدة ولا
   يتغيّر. انظر `samples/roster_sample.csv`.
2. **بطاقات الرموز**: لكل قسم صفحة للطباعة ثمّ القصّ والتوزيع (زرّ الطباعة يحفظ
   PDF من المتصفّح).
3. **التقاويم**: أربع طرق للإدخال، كلّها تمرّ بالتحقّق الصارم نفسه:
   - **من Word (الأسهل)**: نزّل القالب الجاهز من صفحة الاستيراد، املأه في Word
     (النجمة `*` = الجواب الصحيح)، ثمّ ارفعه. تحويل يقيني بلا أي ذكاء اصطناعي.
   - **من Word بمساعدة كلود**: استعمل مهارة `word-to-mihakk` (في `.claude/skills/`)
     لتحويل أيّ ملفّ Word عادي إلى قالب مِحَكّ أو JSON — على طاولتك، لا في القاعة،
     مقترحاً تراجعه. ثمّ استورده.
   - **من JSON**: ملفّ واحد لكل تقويم (انظر `samples/assessment_sample.json`).
   - **تأليف داخلي**: من الصفر في شاشة التأليف مع معاينة الهاتف، أو إدراج من
     **بنك الأسئلة**.

   كل تقويم قابل للتصدير إلى JSON (رحلة ذهاب وإياب كاملة).
4. **الجلسة**: تقويم واحد ← جلسة لكل قسم. أنشئ الجلسة، ثمّ:
   - **بوابة الحضور**: أزِل تحديد الغائبين (تُرفض رموزهم طوال الجلسة).
   - **افتح الجلسة**.
5. **التلميذ**: يمسح QR ← يُدخل رمزه القصير (مثل `07-K7`) ← يؤكّد اسمه ←
   يجيب سؤالاً سؤالاً (حفظ فوري، استئناف بعد الانقطاع) ← يسلّم.
6. **المتابعة المباشرة**: شبكة بحالات التلاميذ، عدّاد المسلّمين، **إشعارات
   الرفض الحمراء**، وزرّ «فكّ القفل» لحالة مشروعة (هاتف نفد شحنه).
7. **أغلق الجلسة**، ثمّ **صحّح**: شاشة تعرض سؤالاً واحداً وأجوبة كلّ القسم عليه
   مصفوفة تحته. المفحوص يقيناً يظهر بحكمه؛ الأستاذ يصادق أو يعدّل.
8. **المساعدة المسائية** (اختيارية، على جلسة مغلقة): مرور دفعي على الأسئلة
   المفتوحة، اقتراح لا حكم، مع تحقّق برمجي من الاقتباس. تعمل من البيت وحدها.
9. **التقارير والتصدير**: بطاقة تلميذ (خمس كفايات + منحنى)، بطاقة قسم (+ **أشيع
   الأخطاء**)، مقارنة أقسام المستوى؛ وتصدير CSV (بترميز `utf-8-sig` يفتح سليماً
   في Excel) وJSON.

> **لا نقطة تدخل تقريراً أو تصديراً قبل تصديق الأستاذ عليها.** المقفلة يقينية
> فتُصادَق آلياً؛ المفتوحة تنتظر قراءة الأستاذ.

## ٦. النسخ الاحتياطي — لا تتهاون

كل التتبّع في ملفّ واحد `data/mihakk.db`. **ملفّ واحد تالف = سنة كاملة من
التتبّع.**

- لوحة الأستاذ ← **نسخة احتياطية**: تُنزّل نسخة بطابع زمني.
- انسخها إلى **مفتاح USB أسبوعياً**.

```bash
pip install pytest
```

الغائب، الفرض بلا تغذية راجعة، رحلة JSON ذهاباً وإياباً، ترميز CSV العربي).

## ٨. البنية

```
app/            منطق النظام (بلا ORM؛ SQLite ملفّ واحد)
  constants.py    الترميز والمجموعات المغلقة
  normalize.py    تطبيع النصّ العربي قبل المطابقة
  codes.py        توليد login_code وتحليل roster_id
  validation.py   التحقّق الصارم من JSON التقاويم
  scoring.py      التصحيح اليقيني + محرّك check_rule
  rosters.py      استيراد اللوائح التراكمي
  assessments.py  حفظ/تصدير/استنساخ + بنك الأسئلة
  reports.py      التجميعات + رسوم SVG مكتوبة يدوياً
  evening.py      المساعدة المسائية (خارج القاعة، اختيارية)
  routes/         student.py، teacher.py
templates/      قوالب Jinja2 (RTL)
static/         css/js محلّية فقط
samples/        نماذج CSV وJSON
tests/          اختبارات
```

المخطّط في `app/schema.sql`. `teacher_id` مُبقى منذ اليوم الأوّل رغم أنّ النظام
أحادي الأستاذ الآن، تفادياً لترحيل قاعدة فيها سنة معطيات لاحقاً.

---

## ٩. المبدأ الحاكم — لا يُخالَف

> التغذية الراجعة الفورية داخل القاعة تأتي من أنواع أسئلة مقفلة ومن قواعد فحص
> نصّية يقينية، **لا من حكم نموذج**. الذكاء الاصطناعي بعد الجلسة فقط، مقترحاً
> يصادق عليه الأستاذ. بلا اتصال، يبقى النظام كاملاً — المساعدة المسائية ليست
> شرطاً، وغيابها ليس حالة خطأ.
