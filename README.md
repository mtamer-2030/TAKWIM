# PHILO-TECH v2 — نظام التقويم والتتبّع البيداغوجي في الفلسفة

نظامٌ **محلّيّ** (Offline/LAN) لأستاذ فلسفة، يعكس المنهاج المغربي بدقّة:
هيكلة ديداكتيكية صارمة (مستوى ← مجزوءة ← مفهوم اختياري ← محور ← نصّ ← سؤال
تحليل، وتمرين إنشاء مرتبط بالمستوى)، تتبّعٌ للمهارات الستّ، وتقاريرُ فردية
وفصلية مع خطط تدخّل علاجي يقترحها **محرّك ذكاء اصطناعي محلّي (Ollama)** على
طاولة الأستاذ — لا في القاعة، ولا في السحابة.

> **PHILO-TECH v2 هو النظام الأساسي والوحيد للتشغيل** — لا إصدار سابق يُشغَّل بجانبه.

- لا إنترنت في القاعة، ولا CDN — كل الأصول (Tabler، Chart.js، HTMX، Alpine،
  pdf.js، الخطوط العربية) **محزومة محلّياً** في `static/vendor/`.
- SQLite حصراً (ملفّ واحد `data/philotech.db`)، aiosqlite + WAL للتزامن.
- التصحيح **داخل القاعة يقينيّ**؛ الذكاء الاصطناعي مقترحٌ للتقارير بعد الحصّة لا حاكماً.
- تدهور لطيف في كل مكان: إن انقطع المحرّك المحلّي أو أداة OCR، لا ينهار النظام.
- واجهة عربية RTL بالكامل، للهاتف أوّلاً. **التلميذ لا يرى نقطة أبداً.**

---

## ١. المتطلّبات

- **ويندوز 10/11** (طُوِّر على HP ZBook مع 32GB RAM) — يعمل كذلك على Linux/macOS.
- **Python 3.11 أو أحدث** ([python.org](https://www.python.org/)، فعّل **Add Python to PATH**).
- شبكة محلّية (أي راوتر) وكابل إيثرنت.
- **اختياري للذكاء الاصطناعي:** [Ollama](https://ollama.com) محلّياً على الحاسوب نفسه.
- **اختياري لاستيراد الصور الممسوحة (OCR):** Tesseract مع الحزمة العربية `ara`.

## ٢. التشغيل السريع

انقر نقراً مزدوجاً على **`start.bat`**. في المرّة الأولى:

1. يُنشئ بيئة افتراضية `.venv` ويثبّت المكتبات من `requirements.txt`.
2. ينسخ `config.ini.example` إلى `config.ini`. **عدّل كلمة السرّ إلزاماً:** يرفض
   الخادم الإقلاع ما دامت على القيمة الافتراضية `change-me-please`.
3. يشغّل خادم PHILO-TECH v2 على `http://0.0.0.0:8000`، ويطبع عناوين الدخول
   الفعليّة مكتشِفاً عنوان شبكتك تلقائياً (لا حاجة لتخمين IP).

اترك النافذة مفتوحة طوال الحصّة. للإيقاف: `Ctrl+C`.

عند الإقلاع تُطبَع العناوين هكذا (مثال):

```
لوحة الأستاذ (هذا الحاسوب):  http://localhost:8000/admin
دخول التلاميذ (الهواتف):     http://192.168.1.50:8000/student
رمز QR للطباعة:              http://localhost:8000/admin/qr
```

يدوياً بدل `start.bat`:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy config.ini.example config.ini
python run.py            REM أو:  python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

> عند أوّل إقلاع تُبذَر المستويات الثلاثة (الجذع المشترك / الأولى باك / الثانية باك)
> تلقائياً. لإنشاء جداول قاعدة v2 دون هجرات Alembic (تطوير): صدّر
> `PHILOTECH_AUTOCREATE=1` قبل التشغيل. في الإنتاج طبّق الهجرات: `alembic upgrade head`.

## ٣. إعداد الشبكة يوم التشغيل الأوّل (اقرأه — هنا يُعطَّل النظام غالباً)

> الخادم **يكتشف عنوانك ويطبعه عند الإقلاع** — لا تخمّن IP. تثبيتُ عنوانٍ ثابتٍ
> أدناه مستحسَنٌ فقط ليبقى العنوان نفسه بعد إعادة تشغيل الحاسوب أو الراوتر
> (فلا تتغيّر روابط الهواتف). العنوان `192.168.1.50` مجرّد مثال — استعمل ما يناسب راوترك.

### أ) ثبّت عنوان IP للحاسوب (مستحسَن)

لوحة التحكّم ← الشبكة ← Change adapter options ← الزرّ الأيمن على الإيثرنت ←
Properties ← Internet Protocol Version 4 (TCP/IPv4) ← Properties ←
**Use the following IP address**:

```
IP address:      192.168.1.50
Subnet mask:     255.255.255.0
Default gateway: 192.168.1.1
```

(سكربت `setup.ps1` يقوم بهذا وبفتح المنفذ وجدولة النسخ الاحتياطي آليّاً على ويندوز.)

### ب) افتح المنفذ 8000 في جدار حماية ويندوز (أكثر سبب يُعطّل اليوم الأوّل)

في **PowerShell كمسؤول**:

```powershell
New-NetFirewallRule -DisplayName "philotech 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
```

بدونها ترى الهواتف «تعذّر الاتصال» رغم أنّ الخادم يعمل.

### ج) اربط الحاسوب بالراوتر بكابل إيثرنت، والهواتف على واي‑فاي الراوتر نفسه.

## ٤. الإعداد (`config.ini`)

> كلمة السرّ إلزاميّة: يرفض الخادم الإقلاع ما دامت `change-me-please` الافتراضية.
> تُحفَظ مجزّأةً (SHA-256) في الذاكرة عند الإقلاع — لا تُخزَّن نصّاً في القاعدة.

```ini
[teacher]
password = ضع-كلمة-سرّ-قوية

[server]
port = 8000
public_url = http://192.168.1.50:8000

[local_ai]
enabled  = true                     ; المحرّك المحلّي على طاولة الأستاذ فقط
base_url = http://localhost:11434   ; Ollama محلّياً — لا سحابة ولا إنترنت
model    = qwen2.5:3b-instruct
timeout  = 300
```

`config.ini` **لا يُرفع إلى المستودع** (مُستثنى في `.gitignore`)، وكذلك كل ملفّات `*.db`.

## ٥. الذكاء الاصطناعي المحلّي (Ollama) — تقارير التدخّل العلاجي

الذكاء الاصطناعي هنا **بعد الحصّة، على طاولة الأستاذ، مقترحاً لا حاكماً**، حفاظاً
على اليقين البيداغوجي داخل القاعة. يعمل عبر محرّك محلّي بالكامل (بلا إنترنت):

1. ثبّت [Ollama](https://ollama.com) على الحاسوب نفسه.
2. نزّل نموذجاً عربيّاً مناسباً، مثلاً:

   ```bash
   ollama pull qwen2.5:3b-instruct
   ollama serve            # يستمع على http://localhost:11434
   ```

3. فعّل `[local_ai]` في `config.ini` (أعلاه).
4. من لوحة الأستاذ افتح **`/admin/ai`**، اختر الفوج، ثمّ «توليد تقارير التدخّل
   العلاجي». تُعالَج التقارير **تسلسليّاً** (تلميذاً تلو الآخر) تفادياً لاختناق
   المعالج/بطاقة الرسوم، ثمّ تُحفَظ في القاعدة (تقرير فردي لكل تلميذ + تقرير فصلي).

إن كان Ollama مغلقاً تظهر رسالة واضحة («محرك الذكاء الاصطناعي غير مشغل…») ويبقى
النظام كاملاً — لا انهيار ولا خطأ 500 (تدهور لطيف صارم).

## ٦. سير العمل

1. **استيراد اللائحة** (`/admin/import` أو `/admin/rosters`): Excel/CSV بأعمدة
   عربية أو فرنسية أو إنجليزية (الاسم، رمز مسار، الفوج، المستوى — تُكتشَف المرادفات
   آليّاً). الدخول للتلميذ برمز مسار أو رمز دخول قصير، بلا حساب ولا كلمة سرّ.
2. **استيراد النصوص والأسئلة** متعدّد الصيغ: Word (`.docx`)، PowerPoint (`.pptx`)،
   PDF، وصور ممسوحة (OCR عربي عبر Tesseract). تُستخرَج ثمّ تُراجَع في مربّع نصّ قبل
   الحفظ — مقترحاً تُصادق عليه، لا استيراداً أعمى.
3. **بناء المنهاج** (`/admin/curriculum`): مجزوءة ← مفهوم (اختياري) ← محور، ثمّ
   نصوص وأسئلة تحليل تستهدف المهارات الستّ (صياغة الإشكال، البنية المفاهيمية،
   الأطروحة، البنية الحجاجية، المناقشة، التركيب)، وتمارين إنشاء مرتبطة بالمستوى.
3.bis **التقاويم بالأسئلة** (`/admin/quizzes`): استورد تقويماً من **JSON** (صيغة v1)
   أو **Word (.docx)** بقالب النظام أو **PDF** بنفس البنية، فيتحوّل يقينيّاً (بلا ذكاء
   اصطناعي) إلى أسئلة **مغلقة** (اختيار من متعدّد، اختيار متعدّد، تصنيف، ترتيب) أو
   **مفتوحة** (جواب قصير/طويل/جدول). أسنِد التقويم لمستوى/فوج وانشره، فيظهر للتلاميذ
   في تبويب «التقاويم». المغلقة تُصحَّح يقينيّاً فور التسليم مع **تغذية راجعة** فورية،
   والمفتوحة تُصحَّح جزئيّاً بقواعد `check_rule` والباقي ينتظر الأستاذ. النقطة لا تُعرض
   للتلميذ — تغذية راجعة فقط (صواب/خطأ + تشخيص البديل)، ويمكن كتمها كلّياً للفروض.
4. **التلميذ** (`/student`): يدخل برمزه ← يتصفّح الدروس والنصوص (قارئ pdf.js) ←
   ينجز التقاويم. حفظٌ فوريّ، واستئنافٌ بعد الانقطاع.
5. **التصحيح والمصادقة**: التصحيح داخل القاعة يقينيّ؛ لا يُحتسب في التحليل إلا
   الإنجاز الذي **صادق عليه الأستاذ**.
6. **التحليل والتقارير**: متوسّط كل مهارة (0..1)، نقطة القوّة والقصور الحرج لكل
   تلميذ، والقصور المنهجي المهيمن للفوج — تغذّي خطط التدخّل (القسم ٥).

## ٧. النسخ الاحتياطي — لا تتهاون

كل التتبّع في ملفّ واحد `data/philotech.db`. **ملفّ واحد تالف = سنة كاملة.**
النسخ يتمّ عبر `sqlite3.backup` (نسخة متّسقة تراعي WAL أثناء الكتابة، لا نسخ ملفّ حيّ):

- **آليّاً عند إغلاق كلّ جلسة صفّية** إلى `data/backups/philotech-<ختم زمني>.db`
  (تدوير تلقائيّ: يُحتفَظ بـ١٤ يوماً).
- **يدويّاً** من `/admin` بزرّ «نسخة احتياطية الآن» (يُنزّل الملفّ فوراً).
- **إلى مفتاح USB** بأمر واحد خارج القرص:

  ```bash
  python -m app.backup --to E:\
  ```

انسخ إلى USB أسبوعياً على الأقلّ — القرص الداخليّ وحده لا يكفي.

```
  db_bootstrap.py تهيئة القاعدة عند الإقلاع (Alembic هو مرجع المخطّط)

  signing.py      توقيع الكوكيز (HMAC-SHA256، السرّ في data/.secret)

  normalize.py    التطبيع العربيّ · validation.py التحقّق · scoring.py التصحيح اليقينيّ
  backup.py       النسخ الاحتياطيّ (sqlite3.backup + تدوير + إلى USB)
  ai_feedback.py  الاتصال بـ Ollama + System Prompts + تدهور لطيف
  services/
    analytics.py  متوسّطات المهارات والتقارير الفردية/الفصلية
    gradebook.py  دفتر النقط · quizzes.py منطق التقاويم والتصحيح
  v2/             مسارات الأستاذ (admin.py) والتلميذ (student.py) + web.py
migrations/       Alembic (env.py + versions/ — ٦ هجرات)
templates/v2/     قوالب Jinja2 (RTL): admin/ و student/
static/vendor/    الأصول محلّياً (Tabler/Chart.js/HTMX/Alpine/pdf.js)
static/fonts/     الخطوط العربية (@font-face)
static/js/        teacher.js · student.js

setup.ps1         إعداد ويندوز (IP ثابت + جدار الحماية + نسخ احتياطي مجدول)
start.bat         تشغيل بنقرة على ويندوز
```

## ١٠. المبدأ الحاكم — لا يُخالَف

> التغذية الراجعة داخل القاعة يقينية، **لا من حكم نموذج**. الذكاء الاصطناعي محلّيّ،
> بعد الحصّة، على طاولة الأستاذ، مقترحاً يصادق عليه. بلا اتصال بالإنترنت يبقى
> النظام كاملاً — المحرّك المحلّي ليس شرطاً، وغيابه ليس حالة خطأ.
