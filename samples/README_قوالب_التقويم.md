# قوالب استيراد التقاويم بالأسئلة — PHILO-TECH v2

ملفّان جاهزان للانطلاق، يستوردهما النظام من `/admin/quizzes`:

- **`quiz_template.json`** — نموذج JSON كامل (٦ أسئلة تغطّي كل الأنواع).
- **`quiz_template.docx`** — نفس النموذج بقالب Word (النجمة `*` = الجواب الصحيح).

كلاهما يتحوّل يقينيّاً (بلا ذكاء اصطناعي) إلى أسئلة تُعرض على المتعلّمين.

---

## قالب Word — القواعد

**الترويسة** (في الأعلى، كلّ سطر على حدة):
```
العنوان: عنوان التقويم
النوع: تشخيصي        (أو: تمرين / فرض)
المستوى: 1BAC        (TC / 1BAC / 2BAC)
المجزوءة: ...
المفهوم: ...
```

**نصّ انطلاق مشترك** (اختياري): `نص s1: نصّ الانطلاق هنا…`
ثمّ يُشار إليه في السؤال بـ `| نص: s1`.

**بداية سؤال**: سطر يبدأ بـ `سؤال)` ثمّ النوع وبيانات مفصولة بـ `|`:
```
سؤال) اختيار | الكفاية: المفهمة | النقطة: 2 | نص: s1
```

**الأنواع** (الكلمة العربية ← النوع):
اختيار ← اختيار من متعدّد • متعدّد ← اختيار متعدّد • تصنيف • ترتيب •
قصير ← جواب قصير • مقال ← إنشائي طويل • جدول.

**الكفايات**: الأشكلة، المفهمة، الحجاج، التركيب، الاستحضار.

### حسب النوع

**اختيار / متعدّد** — كلّ بديل في سطر؛ `*` للصحيح، `-` للخطأ، و`| خطأ=رمز` لتشخيص البديل:
```
* البديل الصحيح
- بديل خاطئ | خطأ=اختزال
```

**تصنيف**:
```
فئات: إشكال فلسفي؛ سؤال معرفي
عنصر: نصّ العنصر => إشكال فلسفي
```

**ترتيب** — العناصر مرقّمة **بالترتيب الصحيح**:
```
1) الخطوة الأولى
2) الخطوة الثانية
```
(أضف `| جزئي: نعم` في سطر السؤال لمنح نقطة جزئية على الترتيب الصحيح جزئياً.)

**قصير / مقال** — مؤشّرات التصحيح (مجموع نقاطها = نقطة السؤال):
```
مؤشر: صيغة استفهامية | 1 | قاعدة= نمط: ؟
مؤشر: ذكر التوتّر | 2 | قاعدة= يحتوي: وعي؛ لاوعي
مؤشر: عنصر يقدّره الأستاذ | 1
```
قواعد الفحص: `يحتوي` / `يحتوي_الكل` / `لا_يحتوي` / `حد_أدنى` / `حد_أقصى` / `نمط`.
مؤشّر بلا قاعدة = ينتظر تقدير الأستاذ في شاشة التصحيح.
للمقال: `سقالة: عنصر؛ عنصر؛ …` عناصر إرشادية تظهر للتلميذ.

## قالب JSON

نفس البنية ككائن JSON (انظر `quiz_template.json`). لكلّ سؤال:
`type, competency, prompt, max_score, payload`، وللمفتوحة `indicators` بمجموع
نقاط يساوي `max_score`. المغلقة: `payload.correct` (فهرس/فهارس) و`payload.diagnostics`.

> **الملفّات الحرّة (Word غير مهيكَل / PDF ممسوح):** حوّلها أوّلاً إلى هذا القالب
> عبر مهارة `word-to-mihakk` (على طاولتك)، ثمّ استوردها.
